# 历史比例缺口下的部分修正成本：本地修复验收

2026-09-28。仅本地代码、测试与只读快照；无生产连接、补采、数据库修改、容器发布、提交或 tag。

## 本轮修改

- 修正成本按有效原始账单桶计算，以微美元取整后累加。部分桶没有历史比例，不再抹掉其它桶已核验的成本。
- 未知金额仍为空；真实零金额为已知零；无效或重叠账单继续阻断整个来源的金额，不借部分金额绕过完整性检查。
- 保留原有来源优先级：完整充值版本成本 → 已知经济事实账成本 → 部分充值版本成本。同一供应商不叠加两个可能重叠的来源。
- 每日明细与月度使用相同来源，部分金额不提升完整覆盖率；最终成本、配对利润发布门禁不变。
- 内部测试扣除仍要求证明其成本包含在被扣来源中，部分账单不能任意减去整段内部成本。
- 缺口提示区分历史比例未覆盖与账单桶内比例变化。使用经济事实账时，仍展示账本自己的阻塞原因。
- 月度缓存版本 18 → 19，报表投影变为 `accounting-partial-correction-v3`。此前已支持的 v1 与 v2 快照仅允许作为明确标记的过期展示，异步重算，不提升为当前结果。
- 没有修改渠道管理共享的金额计算、完整性或余额预计天数逻辑。
