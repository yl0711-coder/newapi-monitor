# Usage 后台账单任务接口：本机验收

## 本轮范围

- 新增 `portal_bill_tasks.go` 与测试，提供创建、查询、取消、下载接口实现。
- 从既有 `createPortalExportTempFile` 抽取共享的生成锁/磁盘检查；普通 CSV 仍使用同一流程，后台生成复用同一进程锁、文件锁和磁盘余量要求。
- **没有在 RegisterPortal 注册新服务或路由，没有启动生产任务循环、改页面或提高导出上限。** 新接口目前仅由本机测试显式挂载。没有提交、打 tag、部署或访问线上。

## 接口与保护

| 方法 | 路径 | 行为 |
|---|---|---|
| POST | /api/logs/bill/tasks | 接受现有预检签发的账单票据，返回任务 ID |
| GET | /api/logs/bill/tasks/:id | 返回状态、进度、字节数、校验值、到期时间及固定错误码 |
| POST | /api/logs/bill/tasks/:id/cancel | 取消任务，禁止再下载 |
| GET | /api/logs/bill/tasks/:id/download | 完成且权限仍有效后下载完整 CSV |

- 所有接口使用既有客户会话鉴权；创建只接受 `ticket`，拒绝客户传入 user_id、组范围、SQL、文件路径或容量覆盖参数。
- 写操作要求同源 Origin 和专用请求头；JSON 请求体最多 16KiB，拒绝额外字段、尾随第二个 JSON。
- 票据绑定客户组、筛选和成员指纹；任务归属额外绑定权限版本、成员控制清单及当前可服务成员。直接读 RDS 的任务不绑定无关的小时事实发布时间，避免正常同步使任务反复失效。
- 创建、生成前后、查询及下载复核权限。真正的账号关闭/删除与临时权限库错误分开；临时错误拒绝本次访问，不误判成撤权。
- 等价票据在任务保留期内复用同一任务，最多 2 个任务、单文件 128MiB；仍保留 5 万条入口限制。生成之间至少 5 秒，取消再创建不能绕过生成节流。
- 下载和原 CSV 共用每组 5 分钟成功下载限额，传输失败撤销占位。复用已验证的 Content-Length、no-store、nosniff 和有界下载实现，不把数据库连接交给下载阶段。
- 不暴露私有路径或原始异常文本，失败或未完成任务不能下载部分内容。

## 验收

- 本机 HTTP 黑盒：正常创建/查询/下载、重复创建只生成一次、两条导出路径共享下载限流，通过。
- 未登录、跨站、缺失来源/请求头、无效票据、客户自报范围、超长请求、尾随 JSON 拒绝，通过。
- 生成失败、取消、跨组访问、凭证撤销、成员投影不一致时拒绝读取，通过；私有部分内容和原始错误文本没有出现在响应。
- 原 CSV 持有生成锁时，后台生成不会调用数据库生成器；锁释放后原 CSV 能正常取得锁，通过。
- 三轮接口竞态测试通过（约 23.24 秒，授权错误细分补丁前）；最终补丁后再跑接口竞态测试通过（约 8.94 秒）。最终授权错误分类单测、既有 TestPortal 全回归通过（约 10.31 秒）。
- 最终代码在断网、无宿主端口、1 CPU / 768MiB 的本机 MySQL 8.4.9 容器中，全部任务接口测试及真实 MySQL → 只读快照 → 后台暂存 → HTTP 下载链路通过；下载完成后来源连接 InUse=0。
- 静态检查和差异格式检查通过。
