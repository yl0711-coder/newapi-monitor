## 本轮实现

- 有限、不可变价格目录；精确模型、服务档位、半开生效时间和输入长度档位匹配。
- 保存价格证据 ID、来源 HTTPS 页面、核验时间；当前观察值禁止倒填到观察时间之前。
- 时间及上下文范围重叠拒绝建立目录，不随机选第一条；不得按模型名相似度、邻近日期或默认档位回退。
- 只对经独立规范化的 OpenAI 文本 Token 计算；总输入包括普通输入、缓存读和缓存写。Anthropic TTL 价格不套用这一适配器。
- 复用既有精确金额内核，USD/百万 Token ×用量×固定7；不读取或反算实际扣费。
- 缺缓存单价且有使用量时拒绝参考金额；确认没有使用量时可不需要该分项价格，不能把未知使用量当0。
- 外部切片和返回结构不能修改运行中的价格快照，无运行时网络或数据库依赖。
