# v1.18.21 与已上线 v1.18.20 的合并核验

- 共同基线：v1.18.18，`ea60179f0096f9629438404d59a08fdad44e5d95`。
- 合并目标：v1.18.21，`d0a9a8095fecbc716c31fba19783e7aa817e742a`，来源分支 `release/v1.18.1`。
- 合入已上线版本：v1.18.20，`bd2f76e2c68dcd45a25bb4a618c9d1b4ea4281ad`。
- 使用独立本机 worktree；没有加入其他开发目录的未提交文件，没有修改线上配置、数据库、运行容器或流量，不合并 main，不覆盖原 tag。

## 冲突处理与完整性

唯一文本冲突为 `monitor/page.html` 底部相邻脚本的缓存版本号，按各自模块的新版本合并：渠道 18、经营核算 58、稳定性 8、排障 18、客户维护 4、预警 3、模型统计 6。保留新增分位格式化脚本，并确保它在稳定性脚本前加载。两边的 CSS 版本和页面入口均保留。

相对共同基线的文件逐字核对：v1.18.20 的 25 个非页面变更文件、v1.18.21 的 80 个非页面变更文件全部与原 tag 相同。共享页面另行检查双方入口、样式及脚本加载顺序。依赖清单和 SQLite 基础文件与 v1.18.21 相同，合并没有追加 schema 或计费公式修改；不代表 v1.18.21 本身没有迁移。
