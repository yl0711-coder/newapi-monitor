## 发布与实际修复分开

发布只替换 Monitor 的固定版本镜像，保留原配置和数据卷，不用 latest，不合入 main；先核对 CI 的提交 SHA、测试与扫描结果。生产操作及停机仍需用户单独授权。

首次部署保持以下开关关闭（未配置时默认关闭）：

```text
MONITOR_FINANCE_GIFT_HANDOFF_APPROVAL_ENABLED=false
MONITOR_FINANCE_GIFT_HANDOFF_LOCAL_EXECUTION_ENABLED=false
MONITOR_FINANCE_GIFT_HANDOFF_LIVE_EXECUTION_ENABLED=false
```

不得为上线直接替换整份生产 .env，避免丢失既有设置。不开启新工具时，新执行台账不进入普通启动迁移。

开启修复需单独核对：可恢复的 Monitor 接收库备份、固定来源目录及 prepared 计划摘要、来源 epoch、主库与事实库的绝对路径、独立只读事实连接、会话鉴权，以及与当前事实匹配的有限授权。不能直接沿用本地副本的任务授权。

超级管理员操作地址为 `/finance/gift-handoff/live`。顺序：只读核验 → 有限授权 → 显式启动 → 检查持久提交 → 复核报表。当前页面一次批准最多 2 个用户小时；不是自动补全整段历史。

页面关闭不停止任务；停止保留已提交结果，撤销不回滚在途已提交事务。重启不自动续跑。失败时先查原因，不能通过重新编号绕过校验。
