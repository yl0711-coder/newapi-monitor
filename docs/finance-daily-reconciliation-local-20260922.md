# 每日修正成本与月表对账（仅本机）

## 范围

接续每日充值修正与经济事实账回退明细，增加两类来源与父期间的逐供应商对账。不改变收入、赠送、内部测试扣减、利润公式、渠道管理或数据库结构；不访问生产，不补采、不提交、不打 tag、不上线。

## 实现

- 在既有日账户账单投影内保留按供应商的充值修正金额，不新增 SQL 查询。
- 按父月选定来源，分别累计各供应商每日成本，核对供应商月金额，再核对父期间已知修正成本合计。供应商之间的差额抵消不能通过。
- 新增每日 `cost_reconciliation`，仅包含 `known_total` 和对账状态。`reconciled` 只证明已知部分在相同父期间、相同供应商和来源范围内守恒，**不表示覆盖完整、客户成本已配对或利润可发布**。
- 缺少零值证据不制造零；负数、溢出、重复供应商、未知来源、供应商金额或父期间金额不符时，不发布新合计。原月表、原两类明细和其他经营字段保留，不因该对账失败中断整个报表。
- 日表两个主金额列合成一个“修正成本合计（含内部）”，小字保留充值/账本来源；旧响应没有对账字段时不由浏览器猜加合计。表头、正常行、空行、失败行均为 17 列。
- 月组件缓存 schema 14，全报表键 `daily-cost-reconciliation-v1`，finance.js v51；内部供应商索引不序列化，对账结果随月组件缓存。
