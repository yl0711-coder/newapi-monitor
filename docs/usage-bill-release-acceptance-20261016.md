## 尚须发布流程确认

- 正式 Dockerfile 全链路构建本机受 Docker Hub 鉴权节点连接超时阻断。已通过的过滤上下文编译及缓存运行层测试不能冒充正式镜像构建；提交后的 CI 必须产出固定版本镜像，再核验该镜像启动。
- `MONITOR_PORTAL_BILL_TASKS_ENABLED` 默认 false。正式部署若启用后台生成，需明确配置 true；关闭后只停用后台模式，保留同步账单路径，不等于隐藏全部账单功能。服务重启后旧任务需重新生成，不承诺跨版本续传。
- 保持单次 31 天、50,000 行、128MiB 上限；超过必须缩小范围，不生成截断的“完整账单”。订阅抵扣等未支持情况明确拒绝；缺少核验依据的原价参考留空，实际收费不改。
- 回退演练首次使用 128MiB tmpfs，触发既有 2GiB 备份余量保护并拒绝启动；将测试 tmpfs 逻辑容量调至 4GiB、内存限额仍 512MiB 后通过。未修改或绕过保护。正式上线仍须检查真实磁盘余量和备份。
- 本轮没有页面交互代码变更，未重新占用用户浏览器；此前交互验收记录保留，不能说本轮又做了浏览器人工下载。

测试通过代表已覆盖场景未发现阻断问题，不是“绝对无 bug”。此文不授权发布。
