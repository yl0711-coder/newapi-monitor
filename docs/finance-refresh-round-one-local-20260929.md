# 经营核算刷新稳定性第一轮：本地验收

日期：2026-09-29。基线：v1.18.10 / 72f8448b69afd1d24da66a7ed30521a3f540137e。

## 范围与边界

仅修改经营核算证据缓存、刷新队列、变更诊断和对应展示、测试。不修改核算公式、数据库表结构、生产配置，不执行线上补数、重启或发布。已有渠道、用户目录、稳定性等未提交修改不纳入独立验收候选。

## 实现

1. 赠送证据缓存以用户/小时证据及核算配置作为范围，不再因整个数据库版本变化生成重复缓存项。数据库版本仍作为安全校验提示；版本变化时重新核验相关原始证据，不能直接信任旧金额。
2. 缓存读取期间发生数据库写入时，分批核验已复用的小时证据；无关写入不再直接导致整张报表失败。单批核验超时为 5 秒，真实证据不一致仍拒绝发布。
3. 事实变更引发的刷新失败增加有限重试状态：前两次为待重新核验，第三次持续失败明确显示异常；退避不能被手动刷新绕过。重试仍由现有页面轮询或后续请求驱动，不新增无限后台循环。
4. 相同查询及相同核算配置返回 202 时保留已显示结果；配置不同则不沿用旧金额。加入安全的变更来源标签，辅助区分证据、渠道目录、账单等变化，不输出用户明细或密钥。
