# Usage 客户账单 CSV：本机第一版

## 边界

独立开发分支 `feat/usage-bill-export-r1-20261015`，基线为 Usage 第一期 `ca35382`。尚未同步后续线上发布提交，未提交、打 tag、推送或部署。不修改 NewAPI、生产库、历史扣费、渠道管理或经营核算。原有日志 CSV 保留；新增账单入口。

用户于 2026-10-16 追加确认，共 14 列：消费时间（北京时间）、账户名、令牌名、分组名、模型、Request ID、类型、普通输入 Token、输出 Token、缓存读取 Token、缓存写入 Token、同口径官方原价参考（元）、实际收费（元）、折扣参考（折）。不包含 IP、上游 Request ID、管理员字段或说明列。

“类型”指请求类别，当前已确认样例为“文本”，不是日志类型“消费”。只导出 type=2 消费日志。无法从历史记录确认请求类别时显示“未确认”，不将音频、图片生成或任务记录默认标成文本；不改变实际收费。原始 13 列样例保留，2026-10-16 新增独立的 14 列“含类型”示例，验收直接与新文件比较，不再临时拼装期望列。

2026-10-16 样式对齐验收：将本机留存的 10 笔真实日志及独立查询所得 Request ID 装入测试专用临时 SQLite，完整经过查询、消费筛选、签名票据、授权复核及 CSV 下载。按 Request ID 对齐后，下载结果与新版示例全部 14 列逐项一致；下载仍沿用使用日志的时间倒序，不改变原有排序。原始示例及生产数据未修改。账单与普通日志的导出说明分区展示，避免元/美元口径混淆。账单和普通导出 Go 回归、31 项前端日志/回滚测试通过；本次没有新增价格覆盖，也未完成真实浏览器人工下载验收。

## 已接入

- 使用日志页“导出账单”，共用当前筛选。全部类型按消费 type=2 导出，选择其他类型时拒绝；充值、退款不计入消费账单。它不是净支付账单。
- 原始整数 quota / 500000，按客户已确认的元口径展示，不能影响原有美元展示或再次乘分组倍率。纯有理数计算，金额显示六位，折数两位。
- 已记录的钱包消费才接受；未知来源和订阅不假定为钱包，也不静默丢行，整份拒绝。历史缺失和异常 Token 留空，不冒充 0；普通输入需明确计量语义。
- 准备阶段冻结筛选、成员指纹、最大 ID、行数和格式，签名票据限时有效。账单专用版本化下载路由与普通 CSV 不可混用票据；不接受客户端覆盖票据内筛选。
- 沿用权限前后复核、查询预算、单文件内存分页、0600 临时文件、磁盘预留、128MiB 文件限制及成功下载限频。超过 5 万条直接拒绝，不提供确认后截断路径。行数变动、订阅/未知来源、写入失败不会返回部分 CSV。
- CSV 文本防公式注入，增加空白字符后的危险前缀保护，仅作用于新账单，不改变普通 CSV。

## 价格覆盖限制：尚不具备通用原价覆盖

当前原价参考只接入用户已确认的样例：`claude-opus-5-5`、2026-10-13 至 2026-10-15、明确 Anthropic 语义及单一线性档位，记录价格须逐项等于输入 4、输出 20、缓存读 0.2、5m 写 5、1h 写 8 美元/百万 Token。依据是本机已核验日志、官方价格核对记录和客户确认的 CSV，不是自动在线价格目录。

参考按同一计费变量计算，未拆分写入量仍展示在 Token 列，但不猜 TTL；实际收费不变。复用既有工具/多模态/边界/倍率/整数额度复核闸门。只有上述价格、范围及复算全部匹配才生成原价参考和折数，不能用实际收费除倍率倒推原价。

其他模型、日期或不完整证据的原价与折数留空，实际收费保留。不能把样例规则扩为所有模型，也不能声称第二期价格功能完整。下一轮需独立完善带来源及适用范围的价格匹配，不静默放宽核验。

- 新账单单元/HTTP 测试：金额和缺 TTL 样例、不确定参考留空、不修改源事实、未知/订阅拒绝、CSV 注入、防跨账号、防篡改、格式隔离、权限变动、删除造成行数变化、50,001 条拒绝等通过。
- 全部 `TestPortal*` 原生回归和 race 通过，`go vet ./monitor` 通过。前端日志/回滚/账单协议测试 31 项通过。CI 测试分片覆盖检查通过。
