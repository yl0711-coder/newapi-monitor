# 历史赠送证据有限修复：HTTP 接入本机验收

2026-09-29。承接 `finance-gift-live-core-local-20260929.md` 的执行内核，本轮只接入现有超级管理员操作、停止和进度查询。不新增自动调度、取证系统或整库替换机制。

## 边界与行为

- 新增超级管理员 GET `/finance/gift-handoff/live` 与 `/finance/gift-handoff/live/control`，沿用既有授权及 POST start/stop 路由。
- `MONITOR_FINANCE_GIFT_HANDOFF_LIVE_EXECUTION_ENABLED` 仍默认 false；与本地模式互斥。不因打开页面、预览、授权、启动 Monitor 或重启服务而执行修复。
- 页面明确提示将修改当前 Monitor 事实库，不修改 NewAPI 数据库；本地页面与在线形态页面使用不同控制地址和浏览器任务存储键。模式不符时禁用操作。
- 复用固定来源摘要、接收库绑定、有限目标授权、过期/撤销检查、任务互斥、文件锁、逐小时事务和持久提交记录。没有客户端自选文件路径或全历史执行入口。
- 正常执行仍有 10 秒冷却及原有时间/范围上限。停止后保留已提交记录，不自动续跑；后续执行必须显式发起且重新核验。
- 进度查询只读；`execution_enabled:false` 表示该查询本身不执行，当前执行能力与任务状态由独立 control 接口返回。缺失台账返回未知状态，不当作零进度或从未执行。
- 事实在授权后改变时，执行核验拒绝过时证据，不覆盖当前事实。
