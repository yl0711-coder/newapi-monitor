## 解析约束

1. missing/null/valid/invalid 四态，明确零不是缺失。
2. 数值以原始数字文本保留，不经过 float64；整数检查 int64 上下界。
3. 支持有界科学计数法；数字字符串暂不自动转换，须取得实际兼容证据再增加规则。
4. 整体大小不超过 128 KiB，请求规则不超过 128 项；极端输入降级，不执行表达式。
5. 重复顶层键、尾随 JSON、非法对象拒绝，避免最后键覆盖产生金额歧义。
6. 未知明确计费模式不能退回倍率计费；损坏阶梯表达式仍保留阶梯类型及无效状态。
7. 内部证据结构不是客户 DTO；客户 DTO 只包含静态标签、经过验证的数字和状态说明，不输出原始表达式、规则条件、任意工具名或管理字段。页面再做 HTML 转义。
8. mode 仅表示格式识别，不表示公式完整或复算通过。暂不生成任何金额。
